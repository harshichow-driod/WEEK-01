# Java Fundamentals – BridgeLabz Fellowship

This repository contains my Java programs and assignments from the **BridgeLabz Fellowship Program**, covering core Java topics like control flow, arrays, methods, strings, and more.

##  Modules
- **01. Java Basics** – Data types, variables, type casting, user input
- **02. Control Flows** – if-else, loops, switch, break/continue
- **03. Arrays** – 1D & 2D arrays, validations, error handling
- **04. Methods** – Static, recursive, dynamic, Math class
- **05. Strings** – Manipulation, built-in methods, exceptions
- **06. Extras** –  
  - Built-in functions (`Math`, `Random`)  
  - Java Date & Time (Java 8+)  
  - **String Handling Practice**  
  - **Problem Solving Practice Programs**

##  Highlights
- Clean, modular code with naming conventions
- No hardcoding; all data via variables or input
- Exception handling and input validation
- Practical examples for hands-on learning
